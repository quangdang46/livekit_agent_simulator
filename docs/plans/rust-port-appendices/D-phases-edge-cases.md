### P1 enrichment — Config, scenario, preflight, YAML (heaviest additions)

These reports add the most new material to P1. The plan's P1 covers config + scenario parsing; the following is the exact behavioral contract.

1. **`_require` semantics (config.py)** — fail iff value is `None` OR (string and whitespace-only). `0`/`false`/`0.0` PASS. Error text byte-exact: ``Missing `livekit.api_key` in .agent-sim/config.yaml. Copy the value from LiveKit Cloud / your worker and try again.`` (pattern reused for `livekit.url`/`livekit.api_secret`/`livekit.agent_name`/`simulator.api_key`). Section-missing errors: ``Missing `livekit:` section in {path}.`` / ``Missing `simulator:` section in {path}.``; missing-file: ``{path} not found. Run `lks init` (or the `init_project` MCP tool) to scaffold .agent-sim/ first.``; bad YAML: ``{path} is not valid YAML: {e}``; non-mapping top level: ``{path} must be a YAML mapping at the top level.``. Unknown top-level config keys IGNORED silently. `int("12abc")` propagates raw `ValueError` (NOT wrapped in ConfigError) — replicate unwrapped propagation or document divergence.
2. **Bool-coercion trap (must replicate or document)**: Python `bool("false") == True`. Affected fields: `observe.lk_transcription`/`lk_agent_session`/`record_audio` (default True), `observe.audio_onset.enabled` (default False), `telephony.wait_until_answered` (default True), `telephony.krisp_enabled` (default False). `_require` handles the None/whitespace case; bool fields are the separate `bool(raw)` path. Decide at P1 kickoff: a `BoolLike` helper (YAML bool→bool, string "false"/"no"/"0"→False, other string→True, matching Python) or documented divergence.
3. **Provider/mode/endpoint/vad coercion**: all `str().strip().lower()`-coerced before validation ("GOOGLE" passes). Value errors byte-exact: `simulator.provider` must be `google` or `openai` (got {v!r}); `simulator.mode` must be `realtime` (got {v!r}); `judge.endpoint_type` must be openai or anthropic; `observe.audio_onset.vad` must be `rms`; `observe.audio_onset.threshold` must be between 0.0 and 1.0 (strict: 0.0 < t < 1.0); `cues.dirs` must be a list; `cues.aliases` must be a mapping; `observe.audio_onset` must be a mapping (or absent). `judge:` absent or non-dict → whole block skipped (judge=None). Non-dict `voice` silently → `{}`. Defaults: `DEFAULT_LANGUAGE="en-US"`, `DEFAULT_TIMEZONE="UTC"`, `DEFAULT_VOICE_MODEL="gemini-3.1-flash-live-preview"`, `DEFAULT_JUDGE_MODEL="gemini-2.5-flash"`. `room_prepare_ms` default 500, `agent_join_timeout_ms` default 25_000 (int()); `dispatch_metadata` = str().strip() or None. `sip_trunk_id` is a legacy alias for `outbound_trunk_id` (sip wins if both). Note `transcript_dedupe_window_ms` code default 15_000 (template says 5000 — code wins).
4. **`config_snapshot` key ORDER is a contract** (dict-literal order): `project, livekit, simulator, judge_enabled, judge, cues, observe, telephony, observe_gaps`. Nested: `livekit{url_host, agent_name, agent_join_timeout_ms, dispatch_metadata_set}`, `simulator{provider, mode, voice_model, voice, language}` (language = voice.language, the authoritative one), `judge{model, http, endpoint_type, api_key_set}` (model falls back to DEFAULT_JUDGE_MODEL; endpoint_type None when no base_url; judge null when judge None), `cues{dirs, alias_keys (SORTED), target_cues_dir}`, `observe{lk_transcription, lk_agent_session, record_audio, data_topics, silence_threshold_ms, audio_onset_enabled, audio_onset_threshold}`, `telephony{outbound_trunk_set, inbound_trunk_set, dial_in_set, sim_inbound_number_set, prepare_ms, wait_until_answered, krisp_enabled}`, `observe_gaps` = `["tool_events"]` IFF (not lk_agent_session) AND (no tool_event_patterns), else `[]`. Secrets NEVER in snapshot. `url_host = url.split("://")[-1].split("/")[0]` — replicate split semantics for urls without "://" and with trailing slash.
5. **YAML digit-quoting (write path)**: `_str_representer` single-quotes a string iff `data.isdigit()` OR (`len>1` and `data[0]=="0"` and rest is digits). So "123", "0", "00", "09" quoted; "0x1F", "1e5", "-1", "1.5", "1_000" PLAIN (YAML 1.1 coercion traps). Applies to ALL strings including mapping keys. Dump params: `default_flow_style=False`, `sort_keys=False`, `allow_unicode=True`, `width=100`. Comments never survive round-trip. `_clean` drops None and empty dict/list values. Read path: decide YAML 1.1 vs 1.2 emulation — PyYAML parses unquoted `on/off/yes/no` as bool and `0123` as int; serde_yaml/yaml_serde are 1.2. Recommended: emulate PyYAML on read (users rely on `enabled: on`).
6. **Scenario parsing — JSONL exactness**: only FULL-LINE `//` (after strip) lines are comments; inline `//` is a JSON error. Blank lines skipped. `_`-prefixed keys stripped from every JSONL record (NOT from YAML). Line 1 must be `kind=Scenario` + `apiVersion == "agent-sim/v1"` (exact strings; error `{path}:{line}: apiVersion must be `agent-sim/v1` (got {…!r})`). Unknown kind → `{path}:{line}: unknown kind {kind!r} (expected one of {sorted(KNOWN_KINDS)})` — 12 kinds: Persona, Context, Simulator, Execute, Dispatch, PassCriteria, Script, Behavior, Plugins, Assert, Caller, Telephony. Spec non-dict → `spec must be an object`. Duplicate kinds: Persona/Simulator/Execute/Dispatch/Caller/Telephony/PassCriteria/Behavior/Assert last-wins; Plugins EXTENDS; Script REPLACES. YAML path: no apiVersion/kind check at all; accepts top-level `id`/`locale`/`tags` (group-wrapper carry-down); `persona.brief is required` (different string than JSONL's `Persona.spec.brief is required — the simulator needs a caller brief`); BOM tolerated by YAML, breaks JSONL `json.loads` (replicate or strip).
7. **YAML group wrapper + multi-doc**: wrapper only checked on sections[0] when `"scenarios"` in it; `scenarios` must be a non-empty list (`{path}: scenarios must be a non-empty list`), exactly 1 item (`group wrapper with {n} scenarios — LKS uses one scenario per file; split into separate files`), item must be dict. Group-level `metadata`/`tags`/`locale`/`id` carried onto the merged scenario only if not already present. Multi-doc merge: list+list APPENDS, everything else overwrite (dict+dict does NOT merge). Trailing `---` → None doc filtered. Empty file → `{path}: empty scenario file` (both formats, same message).
8. **find_scenario/list_scenarios precedence**: YAML shadows same-stem `.jsonl`/`.yml` in `list_scenarios`. `find_scenario`: direct `<id>.yaml` → `<id>.yml` → `<id>.jsonl` first; else scan `*.jsonl` then `*.yaml` then `*.yml` (each sorted, deduped) matching `metadata.id`; first match wins. Scenario-id regex `^[a-zA-Z0-9][a-zA-Z0-9_-]{0,63}$` applied to the QUERY only (a file with id "bad id!" parses fine but is unfindable; find_scenario raises `Invalid scenario_id {id!r}: use letters/digits/[_-], start with alnum, max 64 chars` as ScenarioError). `_write_yaml_atomic` (ops.py:183-199): write `<dest>.yaml.tmp`, validate via `load_scenario_yaml` BEFORE `os.replace` — broken YAML never lands on dest.
9. **Scenario model**: `run_spec = Execute overrides Simulator per-field (None → simulator's)`. `hold_music_timeout_s()`: Execute wins, else `persona.speech_conditions.hold_music_timeout_s`, else None; clamp [5.0, 300.0] inclusive with `:g` formatting in the error (`{where}: hold_music_timeout_s must be between 5 and 300 seconds (got {value:g})`). `effective_locale()`: Persona.language || Persona.locale (stripped) || metadata.locale || "en-US". `dispatch_metadata()`: scenario Dispatch wins over config `livekit.dispatch_metadata`; must `json.loads` at parse. Caller mode 5-value set; `handset_isolation` in {mute_uplink, mute_and_unsubscribe, none, remove} (runtime invalid → silently "mute_and_unsubscribe"). Effective telephony merge scenario > config > builtin (defaults: prepare_ms 3000, wait_until_answered True, krisp False, handset "mute_and_unsubscribe"); `sim_inbound_number` valid as call_to fallback ONLY for outbound_sim_callee. `validate_telephony_for_mode` fail-fast messages: `Scenario {id} mode={mode} requires telephony.outbound_trunk_id in config or Telephony.sip_trunk_id in the scenario.` / `…requires Telephony.call_to (human/PSTN number that will answer). For Gemini-as-callee hairpin use mode=outbound_sim_callee + sim_inbound_number.` / `…requires Telephony.call_to or config telephony.sim_inbound_number (sim DID Gemini answers via Cloud hairpin). Do not put a real handset PSTN here — that is mode=outbound_human_pickup. The DID must dispatch into the sim-room where Gemini already sits (see docs/telephony.md, docs/PROBLEM.md).` / `…requires Telephony.dial_in or config telephony.dial_in (agent-side inbound DID).`.
10. **preflight.rs (port whole file, P1 or P2 — plan puts it at P2; reports give the full contract)**: check ORDER + names: `config` → `livekit.url` → `observe.timezone` → `folders` → `simulator.api_key[{provider}]` → `livekit.api` (gated `if connectivity and result.ok`) → `telephony`. Config fail → early return (result, None), NO folders created, no API check. `livekit.url` fail iff not startswith ws://|wss://|http://|https:// (detail `` `{url}` must start with wss:// (LiveKit Cloud) or ws:// ``). timezone via ZoneInfo try → ``Unknown IANA timezone `{tz}` ``. folders: `mkdir(parents=True, exist_ok=True)` on reports_dir + scenarios_dir (side effect mid-preflight). api_key: stripped, empty → fail `missing — `simulator.api_key` required for provider {provider}`; len < 20 → WARN "Key looks unusually short" (heuristic; still proceeds). livekit.api: `api.LiveKitAPI(url, key, secret)`, exact call `room.list_rooms(ListRoomsRequest())`, fail detail ``Cannot reach LiveKit server API with the configured credentials: {Type}: {msg}``, pass detail "list_rooms OK", finally `aclose()`. telephony: skipped unless outbound_trunk_id or dial_in or sim_inbound_number set; bits `outbound_trunk=set|missing; dial_in=set|unset; sim_inbound=set|unset`, pass iff outbound_trunk_id else warn; plus the three recipe warns (outbound_sim_callee hairpin recipe, `sim_inbound_number set but outbound_trunk_id missing — SIP dial cannot run.`, both → pass note about the Cloud dispatch rule). preflight NEVER aborts the caller process — it returns a result; run_orchestrator runs it but does not gate on it.
